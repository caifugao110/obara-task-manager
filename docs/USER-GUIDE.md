## 1. 开始使用

### 1.1 登录

打开系统地址后进入登录页，输入用户名和密码。登录成功后落到**主页面**（任务录入界面）。

浏览器标签页标题有约定：**主页面固定显示 `Obara Task Management`，其它页面为 `OTM-<页面功能>`**（如 `OTM-任务报表`、`OTM-工时管理`）。同时开多个标签页时，看标题就能分清哪个是哪个。

### 1.2 首次登录必须修改密码

新建的账号（包括系统首次启动时自动创建的超级管理员）**首次登录必须改密**，否则除「修改密码」和「退出登录」外的所有操作都会被拒绝。

- 改密完成后才能进入正常界面。
- 改密界面会实时给出**密码强度条**（4 段，按长度、大小写、数字、符号综合评分）与「两次输入一致 / 不一致」提示，仅作参考，最终规则以后端校验为准。
- 如果当前没处于强制改密流程，访问修改密码页会自动跳回主页。
- **管理员重置了你的密码**：旧会话立即失效，下次操作会提示「密码已被管理员重置，请使用新密码重新登录」；用新密码登录即可，**不会**再次强制改密。
- **一般管理员在管理后台改了自己的密码**：下次登录需要再改一次。

> 注意：强制改密页面依赖「允许用户自主改密」开关。若系统关闭了该开关（默认关闭），处于强制改密流程的账号将无法自行完成改密，需要联系超级管理员处理。部署时应确保该开关与强制改密策略配套开启。

### 1.3 界面基本组成

主页面是 Excel 风格的任务表：

- **行** = 设计人员（按分组显示，分组标题可点击折叠/展开，折叠状态会被记住）
- **列** = 日期（当月）
- **单元格** = 某人在某天的任务，一个单元格可以放多条主任务
- **每条主任务下面**可以挂多行**枪名**，枪名可以单独带工时

**列宽会随窗口自适应**：横向固定显示 4 天，「任务内容」列吃掉剩余宽度——窗口越宽，任务名折行越少；工时列固定 48px 不变，设计人员列与月总工时列各 96px。窗口特别窄（约 1350px 以下）时任务内容列保底 240px，放不下的部分靠横向滚动条查看，不会把字挤成一列。调整浏览器窗口大小或缩放后会立即重排；表格变高出现纵向滚动条时，列宽也会重新计算，保证表头与数据行始终对齐。

页面顶部可筛选只显示某个设计人员或全部人员；底部显示本月任务条目、周末加班、出差和请假汇总，左下角有连接状态圆点。

### 1.4 连接状态与离线模式

左下角状态圆点有三种状态：

| 颜色 | 含义 |
|------|------|
| 绿色「就绪」 | 已建立实时连接，数据实时同步 |
| 琥珀色「需手动刷新获取最新状态」 | 未登录或登录已失效，没有实时更新 |
| 红色/琥珀色「离线」 | 后端不可用或网络断开 |

**离线时系统的行为：**

- 主页面、管理后台、任务报表、工时管理、系统设置、焊枪台账、状态追踪都会显示橙色横幅「当前处于离线模式，此页面禁止编辑」，**所有写操作被拦截**，提示「当前离线，禁止编辑」。
- 登录页和修改密码页同样禁用输入与提交，网络恢复后自动解除。
- **主页面可以继续浏览**：断网瞬间系统会把当前数据存进浏览器本地缓存，刷新页面后即使后端仍不可用，也能用缓存数据查看。缓存只用于浏览，不会覆盖服务器数据。
- 任务报表、工时管理、操作日志会进一步禁用月份切换、刷新、搜索、导出等控件。
- 焊枪台账的所有管理弹窗会自动关闭，表保持只读可打开。
- 网络恢复后，各页面会自动重新加载数据、恢复编辑能力；焊枪台账会重新申请当前表的编辑锁。

> **何时才会判定「离线」**：只由后台心跳决定——每 5 秒探测一次后端，**连续 2 次**（约 6 秒以上）都连不上才进入离线模式。单个接口慢（同步生产大日程、解析大 PDF、共享盘抖动）只会让那一次操作等待或报错，**不会让整站闪一下离线并禁用编辑**；反过来，只要有一个请求成功，就会立即恢复在线。

## 2. 主页面：录入与管理任务

### 2.1 任务类型

每个单元格里的任务可以是以下类型之一：

| 类型 | 说明 | 配色 |
|------|------|------|
| **设计计划** | 常规工作任务，可挂枪名 | 由「任务内容」决定（见 2.3） |
| **出差** | 出差任务，可填出差地点/客户 | 湖水青底、深青字，整行纯色 |
| **事假** | 请假 | 淡红浅色徽标 |
| **休假** | 请假 | 淡蓝浅色徽标 |
| **病假** | 请假 | 淡粉浅色徽标 |

- 切换任务类型时，已填写的任务内容、枪名、枪名工时、出差地点/客户等临时输入**会被保留**。
- 出差和请假类任务的配色是固定的，不参与「任务内容配色」体系，也不可在系统设置里修改。
- 请假（事假/休假/病假）与出差类主任务同样支持上移/下移排序，状态文字居中显示。

### 2.2 录入一条任务

**方式一：双击单元格空白处**新增任务。

**方式二：点击单元格里的加号**（鼠标悬停在任务行上时出现）。单击加号是把该格选为粘贴目标，双击才是新增；**单击选中加号后连按两次空格**也能直接新增（见 2.17）。

**编辑已有任务**：双击任务行进入编辑；**单击选中任务（蓝色描边）后连按两次空格**同样进入编辑（见 2.17）。

在弹出的任务编辑框中填写：

1. **任务名**（如「12345 确认图」）
2. **任务内容**（勾选，见 2.3）
3. **工时**（总工时；有枪名时按枪名工时汇总）
4. **枪名**（可手动填、也可「自动获取枪名」）
5. **纳期**（可自动查询、也可手动指定，见 2.16）

任务字段改动会**自动保存**（停止输入约 0.5 秒后提交），不需要手动点保存。

> **纳期与批量操作入口只对「设计计划」显示**：任务类型是出差、事假、休假、病假时，这些入口自动隐藏。

### 2.3 任务内容（六选一）

任务编辑框里可勾选以下六项，**彼此互斥**，勾选后会为任务名追加对应后缀：

| 任务内容 | 后缀 | 工时规则 |
|----------|------|----------|
| 确认图 | 「确认图」 | 有枪名时按枪名工时汇总 |
| 设计 | 「设计」 | 有枪名时按枪名工时汇总 |
| 确认图修改 | 「确认图修改」 | 有枪名时按枪名工时汇总 |
| 设计变更 | 「设计变更」 | **本身不写总工时**，填枪名后按固定工时（默认 1.5h）逐个枪名计算；没有枪名时手动输入总工时 |
| 既制审图 | 「既制审图」 | **本身不写总工时**，填枪名后按固定工时（默认 0.5h）逐个枪名计算；没有枪名时手动输入总工时 |
| 暂停取消 | 「暂停/取消」 | 见 2.6 |

每个选项的文字都会渲染成一个小色块，底色就是该任务内容在表格里的实际填充色，**勾选前后都能一眼对上表格颜色**。

**切换任务内容会同步重算工时**：任务已有枪名（且已带工时）时，切换内容会按新内容重算各枪名工时，总工时随之更新为枪名工时之和。

### 2.4 颜色规则

任务表格的底色**不需要手工挑色**，完全由勾选的任务内容决定：

| 状态 | 默认底色 |
|------|----------|
| 未勾选任何任务内容 | 深紫 |
| 确认图 | 淡绿 |
| 设计 | 浅黄 |
| 确认图修改 | 浅蓝 |
| 设计变更 | 橙红 |
| 既制审图 | 粉 |
| 暂停/取消 | 纯红 |
| 已完成（标记完成） | 白色 |
| 加急（确认图/设计/确认图修改） | 亮黄 |

- 表格内文字统一为**黑色**（固定，不可配置）；**加急任务整行文字变红**（红色同样固定）。
- 全部底色可在「系统设置 → 计划管理 → 任务内容配色」中调整，支持一键恢复默认。
- **白色（已完成）优先级最高**，不会被任何配色覆盖。

### 2.5 任务加急

任务编辑框顶部、「批量操作」左侧有「任务加急」复选框（默认不勾选）。

- **只有确认图 / 设计 / 确认图修改支持加急**，且必须先勾选任务内容才能勾选加急。
- 勾选后底色改为加急配色（默认亮黄），整行文字变红。
- **设计变更 / 既制审图 / 暂停取消没有加急状态**，勾选这三项时加急复选框不可用，提示「只有确认图 / 设计 / 确认图修改有加急状态」。
- 取消任务内容时，加急一并取消。

### 2.6 暂停 / 取消

「暂停/取消」是与其他任务内容并列的独立状态。

- 任务名后缀为「暂停/取消」，整行**纯红底 + 黑字**。
- **工时沿用切换前的内容**：勾选时不清空工时。从其它内容改过来时，保留其原有工时（规则算出的或用户已填的，含枪名工时）；新增空白任务则为 0。
- **0 也能直接保存**，这是它和其他任务最大的区别（普通任务有枪名时工时必须大于 0）。
- 工时不为 0 时，与普通任务一样计入日合计、月总工时、日报、工时管理、排行榜、任务报表等**所有统计与导出**。
- 不参与加急配色。

**快捷操作：在任务名输入框末尾直接敲「暂停」**（新增、编辑弹窗都可以）——输入框里的「暂停」两字会立即被去掉、复选框只勾中「暂停/取消」，同时清掉原有的「确认图 / 设计 / 既制审图」等后缀。保存时统一写成「暂停/取消」。六项复选框始终互斥，不会出现「既制审图 + 暂停/取消」同时勾选。输入「取消暂停」这类说明性文字不会被误判。

> 任务名后缀是最终依据：把后缀改成其它内容或清空，就退出了暂停状态。

### 2.7 工时填写规则

- 主任务总工时与枪名工时的单元格，**值为 0 或为空时不显示数字**（避免 0 工时任务满屏 `0`，暂停/取消任务尤其常见），只有大于 0 才显示。
- 悬停在「暂停/取消」任务的工时格上会提示「工时沿用当前值，0 也能保存；不为 0 时计入工时统计」。
- **枪名存在时，该枪名工时必须大于 0**；唯一例外是「暂停/取消」任务，其枪名工时允许为 0（不能为负数）。
- 新增枪名行时会**自动填充默认工时**：
  - 确认图 / 确认图修改 / 设计：按「枪名所在台账表专用规则 → 机型 C/X 回退规则 → 固定兜底（2h / 0.75h / 3h）」依次取值。
  - 设计变更 / 既制审图：直接取系统设置中的固定工时（默认 1.5h / 0.5h）。
  - **已手动输入的工时不会被覆盖**；修改枪名时，自动填充的工时跟随新枪名刷新，手动输入的保留。

### 2.8 枪名

#### 自动获取枪名

任务编辑框里点「自动获取枪名」，通过仕样号查询焊枪台账中匹配的枪名列表，一键填充到当前任务。

- 支持去除中文后缀（如「样」「A」等）和变体标识做归一化匹配。
- 匹配结果分三段排列：**可添加 → 已安排（倒数第二段）→ 已存在（最底部）**。同段内保持台账原顺序。
- 已被**其它**主任务使用的枪名标为**天蓝色**，含义与台账页一致。
- 已被**当前任务**使用的枪名标「已存在」，复选框禁用。
- 勾选后确认添加时的去重规则：
  - 当前任务里已经有的枪名**跳过**（重复勾选不会产生同名枪名行）
  - 标「已安排」（被其它任务用过）的**可以照常添加**——同一焊枪在不同任务里重复安排是正常业务
  - 提示语按实际新增数量显示（如「已添加 2 个枪名」）

#### 枪名一键复制

鼠标移到枪名行上，操作按钮组最左侧（拖动手柄左边）出现**绿色复制按钮**，点击把该枪名原文写入剪贴板，按钮变绿打勾、1.5 秒后恢复。可直接粘到台账、聊天窗口或其它系统。

- 所有登录用户都可用，不限管理员。
- 点击不会触发枪名行的选中、拖拽或双击编辑；空枪名不显示按钮。
- 非 HTTPS 访问（如内网 `http://192.168.x.x:5173`）时浏览器可能不允许异步剪贴板接口，系统会自动降级为临时文本框选中复制，功能不受影响。

#### 拖动枪名

**管理员**拖动枪名行右侧的手柄，可把单个枪名（连同工时）移到**任意设计人员、任意日期**的任意主任务。

- 落在目标主任务的某条枪名上 → 插入到该枪名之前；否则追加到末尾。
- **会被拦截的情况**：
  - 目标主任务已存在同名枪名 → 「目标主任务已存在枪名「xxx」，无法移动」
  - 目标主任务没有任何枪名 → 「目标主任务没有枪名，不能移入枪名」（这类行只有主任务自身内容，塞入枪名会让主任务工时被枪名工时取代）
  - 目标为请假/出差类任务 → 拦截
  - 落点仍在源主任务内 → 「同一主任务内请使用枪名行的上移/下移箭头调整顺序」
- 源主任务最后一个枪名被移走时，**源主任务一并删除**（撤销时自动重建）。
- 拖动前会先保存源/目标单元格的待提交内容，避免未保存的输入丢失。

#### 把枪名拖到「没有主任务」的位置

- 拖到**没有任何主任务的空白单元格**：整格绿色高亮、浮层提示「松手新建主任务」，松手后按源主任务的名称在该格新建一个主任务（工时 0），再把枪名移入。
- 拖到**已有主任务的单元格最下方的加号**上：仅加号高亮、浮层提示「松手在下方新建主任务」，新主任务追加到该格末尾。
- 新建主任务的完成状态跟随被移动的枪名（枪名已完成则同样标白，未完成则沿用枪名颜色）。
- 两种新建都可撤销：撤销把枪名移回后，新建的空主任务会自动删除。
- 松手回到**源单元格的空白处**视为取消（不提示）。
- 落在已有主任务的格子里、但既没压住任务行也没压住加号：提示「该位置没有主任务，请拖到已有主任务上，或拖到该格最下面的加号上新建主任务」。

#### 调整枪名顺序

同一主任务内的枪名顺序，用枪名行上的**上移 / 下移箭头**调整（连同工时一起换位）。拖拽手柄不承担同任务内排序。移动与排序均支持撤销/重做。

#### 删除枪名（管理员）

鼠标移到枪名行上，操作按钮组最右侧的**红色垃圾桶按钮**用于删除该枪名。

- 点一下**不会立刻删除**，先弹出「删除枪名」确认框，列出**枪名、设计员、日期、所属主任务**；点「确认删除」才真正删掉。
- 删除枪名的同时，该枪名行上的工时也一并去掉；**主任务本身不会被删除**（即使删到一条枪名都不剩），剩下的枪名与工时不受影响。
- 删错了按 `Ctrl+Z` 撤销即可找回（枪名与工时一起恢复）。
- 单元格被他人锁定、或处于离线模式时，删除会被拦截并给出提示；普通用户看不到这个按钮。

### 2.9 拖动任务

- 拖动任务整行可**移动到别的单元格**。拖动时指针扫过目标单元格内的某条主任务，落点为**该任务之前**（插入其上方）；未命中任何任务时追加到该单元格末尾。
- **按住 `Ctrl` 拖拽 = 批量复制**（不是移动）。
- **拖拽预选中提示**：目标位置显示插入标记线（4px 高），可放置为绿色、不可放置为红色。
- **重复任务拦截**：若目标单元格已存在**内容完全相同**的主任务，标记线转红、浮层边框转红并显示「重复任务」徽标，光标变为禁止符，松手时整批拒绝，提示「目标已存在内容完全相同的主任务「xxx」，拒绝复制/拒绝移动」。
  - 「内容完全相同」指：任务名（去掉首尾空格后严格相等）、工时、请假类型、枪名数组（**数量与顺序都要一致**）。
  - **任务颜色、枪名颜色不参与比对**——颜色不同不算重复。
  - 多选复制时以整个多选集合为对象一次性检查，**任一重复即整批拒绝**。
  - 拖回自己所在的单元格：移动操作静默无动作（不提示），复制操作会真复制一份（同样受重复检查约束）。
- **弹窗也能拖**：主页面「新增/编辑任务」、快速取号、确认图修改、确认图安排这几个弹窗，以及焊枪台账「担当人员」分配面板，都可以**按住标题栏空白处拖动**整个窗口，把弹窗挪开、露出背后的表格行来对照；标题栏上的按钮和输入框不会被误拖。每次重新打开、或在弹窗里切换目标人员/日期时，会自动回到屏幕中央。

### 2.10 复制、剪切、粘贴、撤销

- **多选**：选中任务后按住 `Ctrl`（Mac 为 `Cmd`）点击其它任务。
- `Ctrl+C` 复制、`Ctrl+X` 剪切、`Ctrl+V` 粘贴、`Delete` 删除。
- **选中单条任务后连按两次空格 = 直接编辑该任务**（等同双击）；选中加号后连按两次空格 = 直接新增该格任务（见 2.17）。
- `Ctrl+Z` 撤销、`Ctrl+Y`（或 `Ctrl+Shift+Z`）重做。**同一用户最多保留 10 步撤销和 10 步重做记录**，主页面所有操作（包括删除单个枪名）都可撤销。
- 快捷键提示语：
  - `Ctrl+C` → 「粘贴已准备」
  - `Ctrl+X` → 「剪切已准备」
  - `Ctrl+V` → 「任务已复制」
  - 无法撤销时 → 「暂无可撤销操作」

**单元格级粘贴**：单击单元格最下方的「新增任务」加号，可把该格选为粘贴目标（加号常亮），此后按 `Ctrl+V` 直接把复制的任务粘进该格最下方。焦点离开加号（按 `Esc` 或点击别处）即取消选中。未选中任何单元格时，`Ctrl+V` 按任务级粘贴处理。

### 2.11 标记完成状态

开启「允许登录用户修改本人设计计划完成状态」后，普通用户可把**本人同名设计员**的设计计划任务标记为完成（变白）或标记未完成（恢复原色），主任务和枪名单独行都可以标记。

**能看到标记入口的条件**（缺一不可）：

1. 已登录
2. 非离线模式
3. 任务不是请假/出差类
4. 普通用户还需**设计人员姓名与登录用户姓名去掉首尾空格后严格相等**（空格、全半角差异都会导致入口不出现）

管理员在离线时整体降级为只读，标记入口同样隐藏。非管理员**只能**标记白色或恢复，其它颜色会被后端拒绝。

**改色与完成状态的联动规则：**

- 管理员在主任务上改色（非白色、非「恢复」）时，其下**所有枪名一并改成同一颜色**，原先标白（完成）的枪名也会被染成新色——同一条任务不该出现「主任务有色、子枪名仍完成」的矛盾行。
- **枪名全部为白色时，主任务自动标白**；只要有一个非白枪名且主任务为白色，主任务自动恢复原色。枪名增删、移动后都会重算，不需要人工再点一次主任务。
- 标记操作会实时同步给其他人，对方会在该任务行（或具体枪名行）看到「正在修改任务状态」的行内脉冲徽标。

### 2.12 多人同时编辑

编辑会话已细化到**单条主任务**：同一设计人员同一天的**不同主任务允许多人同时编辑、互不干扰**，只有同一条主任务被他人占用时才互斥。

- 他人正在编辑时，该任务行内会显示红色脉冲徽标「AAA 正在编辑」；如果对方在改完成状态，枪名行显示「AAA 正在修改任务状态」并隐藏悬停操作按钮。
- 操作被拦截时提示「AAA 正在编辑该任务，暂无法操作」或「AAA 正在修改该任务的完成状态，暂无法操作」。
- **同一用户同时只能编辑一条主任务**，切到别处会自动释放上一条。
- **新增主任务不占用编辑会话**，不会被他人拦截。

### 2.13 批量查找替换

「批量操作」支持在**指定月份或全表**范围内查找并替换任务名和枪名中的文本，**执行前可预览所有匹配结果**。

- 匹配徽标：枪名匹配显示完整枪名（如「枪名SRTC-2C00001：2 处」）；任务名匹配优先显示其中的仕样号（如「任务仕样号12345：1 处」），无仕样号时显示「任务名」。
- **点击查找结果可定位到底部表格中的目标任务**：系统先选中该任务（蓝色边框），若目标人员被当前筛选隐藏则自动切换筛选条件、展开对应分组，随后把任务单元格滚动到行+列居中。
- 定位时模态框透明度降到 20%，方便透过弹窗看结果；鼠标移回弹窗或 3 秒后自动恢复。
- 查找结果行支持键盘操作：`Tab` 聚焦后按 `Enter` 或空格触发定位。

### 2.14 定位到任务

- 打开主页面时会**自动把「今日」列滚动到视图中央**。点击左下角状态圆点、或连按两次 `Ctrl` 可随时重新定位（只滚动，不重连、不刷新）。非当前月份时不生效，提示「当前不在本月视图，无法定位今日任务」。
- 支持 URL 参数直接跳转：`?date=YYYY-MM-DD&designerId=xxx&itemId=xxx` 可跳转到指定任务并自动选中、滚动定位。
- **保存后自动定位**：新增任务、`Shift`×2 快速添加确认图修改、`Space`×2 取号后安排确认图，写入成功后都会收起弹窗并滚动到刚生成的任务（必要时自动切月份、展开分组、放开人员筛选），任务行闪一圈绿色高亮约 2.6 秒。

### 2.15 人员分组、排序与隐藏

- 设计人员按分组显示，点击分组标题可折叠/展开，折叠状态保存在本地。
- **调整顺序**（仅管理员）：鼠标移到设计人员姓名上，姓名下方出现上移/下移按钮，点击在同分组内与相邻人员交换。跨分组不移动；搜索筛选状态下只与当前可见的相邻人员交换。保存失败会回滚并提示。
- **隐藏人员**（管理员，在管理后台「设计人员列表」点眼睛图标）：该行姓名置灰加删除线并带「已隐藏」标签。隐藏人员在「全部」和分组筛选下不显示，但在顶部下拉菜单中**单独选中该人员时仍然可见**；批量操作定位到隐藏人员时会自动切换筛选条件使其可见。
- 顶部下拉菜单可筛选指定设计人员或全部人员。

### 2.16 纳期

- **自动查询**：新增任务时「显示纳期」默认勾选。任务名中能提取到与系统配置位数一致的仕样号时，保存时自动查询仕样书纳期并拼到任务名末尾 `[M/D]`；输入纯仕样号时还会在输入框右侧实时预览纳期标签。
- **查不到纳期不阻断保存**，可切到「手动输入」自行填写。
- **手动输入**：任务编辑框中可直接设置纳期日期，**覆盖**仕样书 PDF 提取的纳期。
- **批量更新纳期**：手动点击纳期更新时，会把所有与该任务**同一仕样号**的计划任务一同更新或添加纳期，完成后提示已为多少个相同仕样号的任务添加了纳期。

### 2.17 快捷键

| 快捷键 | 功能 | 前提 / 说明 |
|--------|------|-------------|
| `Ctrl+C` | 复制选中的任务 | 需先点击/聚焦到任务 |
| `Ctrl+X` | 剪切选中的任务 | 同上 |
| `Ctrl+V` | 粘贴任务 | 同上；或先单击单元格加号，粘到该格 |
| `Delete` | 删除当前聚焦的任务 | 任务获得焦点时 |
| `Delete` | 删除全部已选中的任务 | 全局（未打开弹窗、焦点不在输入框时） |
| `Ctrl+Z` | 撤销 | 全局，最多 10 步 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 | 全局，最多 10 步 |
| `Ctrl` 连按两次 | 定位到今日任务 | 两次间隔 400ms 内；**离线时仍可用** |
| `Shift` 连按两次 | 快速添加「确认图修改」 | 仅管理员；离线停用 |
| `Space` 连按两次 | 选中加号 → 新增任务；选中主任务 → 编辑该主任务；**没有选中时** → 焊枪名快速取号 | 新增/编辑仅需管理员；取号还需台账权限；离线停用 |
| `~` 连按两次 | 复制选中的主任务为表格 | 仅管理员；离线停用 |
| `Esc` | 取消选中、关闭弹窗、结束编辑 | 有弹窗时优先关弹窗 |
| `F11` | 全屏 / 退出全屏 | 与页脚按钮状态同步 |

**通用说明：**

- 所有快捷键同时接受 `Ctrl` 与 `Cmd`（Mac），上表统一写作 `Ctrl`。例外：**连按两次 `Ctrl` 只认物理 `Ctrl` 键，Mac 上连按两次 `Cmd` 不生效**。
- 两条录入类快捷键（`Ctrl+C` 等）需要先聚焦到任务才生效；`Ctrl+Z`/`Ctrl+Y`/`Esc`/全局 `Delete`/连按两次 `Ctrl` 是全局监听。
- 连按两次 `Ctrl` 的判定，在两次之间按下其它键（如 `Ctrl+C`）或鼠标（`Ctrl`+单击、`Ctrl`+拖拽）时立即打断并重新计数，不会与录入类快捷键冲突。
- **连按两次 `Space` 有三个含义，按「弹窗 → 选中」的顺序判定**：有弹窗打开时完全不接管空格；选中了加号 → 新增任务；选中了单条主任务 → 编辑该主任务；两者都没有才呼出「快速取号」。也就是说，只要页面上有选中的加号或任务，`Space`×2 就不会再弹取号窗，先按 `Esc` 取消选中即可恢复。
- **离线模式下 `Shift`×2 / `Space`×2 / `~`×2 三条快捷键彻底停用**（按下完全无反应，也不会弹「当前离线，禁止编辑」），只有 `Ctrl`×2 定位今日任务照常可用。
- 选中任务后按任意键**不会**出现浏览器默认焦点框，选中态只由 2px 蓝色描边表示。

其他常见提示原文：`请先复制任务`、`剪切失败`、`粘贴失败`、`无法撤销此操作`、`无法重做此操作`、`撤销失败`、`重做失败`。

#### Shift 连按两次：快速添加「确认图修改」

连按两次 `Shift`（间隔 400ms 内，光标不在输入框内）呼出枪名搜索弹窗。

1. 搜索并选择一个枪名（**空关键字不展示候选**，需输入后再搜；台账里没有的枪名也可直接按输入值添加）。
2. 「确认图修改」任务会默认安排给**该枪名当前所在任务的设计员**（可改），日期与工时同样可改。
3. 工时按「枪名所在台账表专用规则 → 机型 C/X 回退规则 → 固定兜底 0.75h」自动填充。
4. 任务名按「台账客户列 + 空格 + 确认图修改」生成；台账未填客户/仕样时，沿用该枪名原来所在任务的名称，只把尾部的「确认图」「设计」等类型换成「确认图修改」。**任务名在弹窗里可手动修改**，改动后出现「恢复默认」入口可一键还原。

弹窗右上角有两个开关：

- **「全表搜索」（默认关闭）**：关闭时只在「日期」所在月份的任务里搜索枪名，开启后搜索所有月份；没有结果时可直接点「搜索全部月份」一键开启。
- **「显示纳期」（默认打开）**：按任务名中的仕样号查询纳期并拼到末尾 `[M/D]`，任务名旁实时显示「已带纳期」/「无纳期」/「纳期查询中…」，关闭会同步移除已带上的纳期。提交前还会兜底补全一次，手动改名后同样生效。

目标设计员当天已存在**相同仕样号**的确认图修改任务时，可选择把枪名**添加进已有任务**而不是新建，该复选框**默认勾选**（可取消）。添加成功后弹窗自动关闭并定位到该任务。

#### Space 连按两次：选中后新增 / 编辑任务，或焊枪名快速取号

连按两次 `Space`（间隔 400ms 内，光标不在输入框/按钮等可交互元素内）按「弹窗 → 选中 → 取号」的顺序判定，同一个键位承载三件事：

| 当前状态 | 连按两次 `Space` 的结果 |
|---|---|
| 有弹窗打开 | 不接管空格，避免吞掉弹窗内按钮的空格激活 |
| 单击选中了某格加号（加号常亮） | 直接进入该格的**新增任务**弹窗（等同双击加号） |
| 单击选中了某条主任务（蓝色描边） | 直接进入该任务的**编辑**弹窗（等同双击任务） |
| 什么都没选中 | 呼出「焊枪名快速取号」弹窗，需**管理员且具备台账访问权限** |

多选（`Ctrl`+单击选了多条）不进入编辑；页面上有选中时 `Space`×2 不会再弹取号窗，按 `Esc` 取消选中即可恢复。下面只讲取号部分（需**管理员且具备台账访问权限**），呼出取号弹窗后：

1. 选择焊枪台账的**分类**，再选**表格**。
2. 弹窗直接定位到该表**最新的未取行号**（已有行数 + 1），按该表规则预置枪名。
3. **首号枪名的前缀可直接改写**：本批每个号都沿用同一前缀，编号继续按规则递增（如标准 `SRTC-2C15023` 改成 `SRTC-5C15023`，取 3 个 → `SRTC-5C15023` / `SRTC-5C15024` / `SRTC-5C15025`）。改过后底部出现对照条与「恢复」按钮；**自定义前缀只作用于本次取号，不写回表规则**。
4. **取号数量可填 1–10**，从最新未取行号起连续占用多个序号，预览区逐个列出将生成的枪名与序号。
5. 填入客户/仕样号（纯仕样号自动解析客户名），按 `Enter` 或点「确认取号」写入台账——**时间列自动填当天、担当自动填当前操作者**。

> 仕样号查不到客户时，提示分两种：**琥珀色「未查到该仕样号的客户信息，将按输入内容保存」**表示这份仕样书确实不存在（不影响取号）；**红色「无法访问仕样书共享目录（<路径>），请检查网络连接或联系管理员」**表示共享盘不通，此时请先恢复网络再查，否则客户名会是空的。

会被拦截的情况：

- **表正被他人打开**（持有表级独占锁）→ 在弹窗内直接置灰并标注「XXX 打开中」，既不允许取号，也不提供只读查看；等对方结束后点右上角刷新恢复。
- 未配置焊枪名规则的表 → 不可取号。

取号成功后弹出「已取号成功」结果框（绿色头部，逐条列出枪名与台账序号），底部可**复制枪名** / **快速安排这 N 个确认图** / **继续取号**，`Esc` 或点遮罩关闭。

- 结果框左下角的「快速安排这 N 个确认图」**只把本次取到的这几个枪名**带进安排浮层，不掺今天先前取的号；页头的「安排确认图」入口仍按今日全部取号带出。
- 打开确认图安排浮层时，**取号弹窗会整体隐藏**，关掉浮层后自动恢复，两层窗口不会叠在一起互相遮挡；`Esc` 仍是逐层回退：浮层 → 结果框 → 取号弹窗。
- 关掉结果框后客户自动清空、数量与首号前缀保留（关掉弹窗重开时前缀回到该表标准值），右栏保留「上次取号 #A–#B（N 个）查看」的回看入口，可连续取下一批号。
- 上次使用的表与数量会被记住，下次呼出直接停在原表。

#### ~ 连按两次：复制选中主任务为表格

选中主任务（蓝色描边即选中态）后连按两次 `~`（间隔 400ms 内），可把任务按「Excel 框选复制」的方式写进剪贴板。**仅管理员**。

- 内容为**主任务行 + 每个枪名行**，**只有任务名/枪名一列，不带工时列**，形式是**带底色和黑框线的表格**（不是图片）。
- 可直接粘贴到 Excel / Word / 网页编辑器：文字可选中、可编辑，底色与框线跟着走。纯文本场景拿到的是每行一条名称的纯文本。
- **断行位置与屏幕上完全一致**：粘贴尺寸整体等比放大（字号约 14.67px），每行字数不变，所以折行位置仍与屏幕一致；任务名列宽度按页面实测。
- 支持多选，但**只能选同一个人同一天的主任务**，否则提示「只能复制同一个人同一天的主任务，请重新选择」；行顺序按表格里的先后排列。
- 不含设计员姓名、日期、操作按钮与蓝色选中描边。
- 第一次按下会先提示「再按一次 ~ 复制选中主任务为表格」，用来确认按键已被识别。
- 任务行**没有**复制表格的悬停按钮，只走这个快捷键。

> `~` 在物理键上是 `Shift`+`` ` ``，连按 `~` 必然连按两次 `Shift`。系统已处理该冲突：「快速确认图修改」的判定会检查最近 500ms 内是否按过 `~`，按过就直接打断，不会误弹确认图弹窗。

### 2.18 页脚

- **上次登录时间**（精确到分钟，本地时区）：取本次登录之前那次成功登录的时间，首次登录时显示本次登录时间。
- **全屏 / 退出全屏**按钮：图标与文案随状态变化；`F11` 已改为与按钮等价（用 `Esc` 退出时状态也会同步）。
- **状态圆点**：见 1.4。
- **操作说明弹窗**（仅管理员可见入口）：点击问号图标打开，内含「拖拽录入」「快捷键录入」「界面快捷操作」三栏，讲解双击新增、拖动排序、`Ctrl`+拖拽复制、拖动枪名手柄等鼠标操作，以及各快捷键。
- **修改密码**：点击右上角用户姓名可直接打开改密弹窗（无需跳页）。该入口仅在「允许用户自主改密」开启时显示（默认关闭）。

## 3. 任务报表

任务报表包含两大功能：**仕样进度管理**（按仕样号查进度）和**枪名周期管理**（按枪名查流转）。

### 3.1 仕样进度管理

输入仕样号搜索（位数由系统设置控制，5 或 6 位），页面会显示：

- **仕样进度百分比进度框**：按「确认图」「确认图修改」「设计」三类统计，**每个枪名计为一个小任务**，主任务标记完成（白色）时其下枪名视为已完成。显示「已完成 X/Y（Z%）」，百分比按进度阶段着色（≥67% 绿、34%~66% 橙、≤33% 红）。进度条可点击定位到对应主任务。进度框不受「仅显示未完成任务」开关影响。
- **该仕样号下的全部枪名**（默认显示，无需开关）：去除后缀 L 或 R（不区分大小写）后去重，只列唯一枪名。

### 3.2 筛选与开关

- **「仅显示未完成任务」（默认关闭）**：开启后实时过滤掉已标记完成的主任务与枪名，匹配数量与结果卡片同步变化，**切换即时生效无需重新搜索**。
- **日历日期筛选器**（匹配结果行右侧的胶囊形按钮）：
  - 点击按钮**任意位置**即可展开（不用专点箭头），再点一次 / 点空白处 / `Esc` / 点「完成」收起；面板以按钮右端为基准向左展开，不会贴到右边缘。
  - 日历只把「本次结果中确有任务」的日期渲染为可点（蓝色加粗 + 小圆点，悬停显示当天任务数），其余日期置灰。
  - **点日期即加入选择、再点一次取消，面板不关闭，可连续点多个（可跨月翻页继续选）**；已选日期在面板顶部以蓝色小标签罗列，每个带 × 可单独移除。
  - 按钮选中后蓝底高亮：单选显示「日期 + 星期」，多选显示「已选 N 天」，右侧徽标为当前命中任务总数，按钮内 × 一键清空。
  - 所选日期均无任务时给出空状态卡片并可一键回到全部；**修改仕样号会自动清空日期筛选**。
  - 筛选只影响匹配任务卡片，上方「仕样进度」与枪名列表仍按全部搜索结果统计。

### 3.3 枪名周期管理

支持按枪名搜索，结果按日期从早到晚排序。

### 3.4 通用规则

- 两个搜索区域都有「全表搜索」开关，**默认关闭**；开启后搜索所有月份。
- 页面是否有权限取决于「任务报表」权限设置；「启用任务报表」关闭后，一般管理员和普通用户自动关闭；打开后自动打开。普通用户打开时，一般管理员不能关闭，并会给出提示。

## 4. 工时管理

### 4.1 月度工时统计

- 可开启「**不含周末加班**」，重新按去除周末后的工时统计。这里的周末加班按主页面日期覆盖规则计算。
- 人员名称下方显示周末加班工时，口径同上。
- **悬停在人员上**可查看设计计划总工时、出差总工时、出差日期和每日出差工时。出差累计为湖水青色卡片，与主页面出差任务配色一致。
- 榜单按数值倒序，前三名有主题色名次徽章（数值为 0 时不高亮），行内淡色底纹表示相对榜首占比。
- 人员超过 10 名时，卡片底部提供「展开全部 N 人 / 收起列表」，卡头也有「展开 / 收起」快捷按钮，两处联动。
- 卡头固定在顶部，名单在独立滚动区内滚动并按整行停靠，不会有人名被卡头盖住或切成半行。

### 4.2 月度请假统计

- 可开启「**不含休假**」，重新按去除休假后的请假工时统计。
- 悬停人员可查看请假明细。
- 当月全员均无请假记录时显示空态提示，不再列出 0 小时名单。

### 4.3 统计分组

页面顶部「统计分组」默认选中**当前登录人员所在小组**：

1. 账号上设置了分组 → 用账号的分组
2. 未设置 → 取**同名设计人员**的分组（姓名比对忽略首尾空格）
3. 两者都取不到（如超级管理员、未建设计人员档案的账号）→ 回退到「全部人员」

可随时切换到其他分组或「全部人员」，两张卡片共用同一范围，卡头副标题标注当前分组、人数与合计。

### 4.4 暂停/取消任务怎么统计

标记为「暂停/取消」的任务，工时不为 0 时与普通任务一样计入本页所有统计（月度工时、周末加班、请假、出差明细）。

## 5. 焊枪台账

焊枪台账采用**分类 → 表 → 行**三级结构。默认分类包括 `X2C`、`X2C-V2`、`X2C-V3`、`GLOBAL`、`PSW`、`IT`、`ROBOT`、`EQ`、`TOYOTA`、`PROJECTION GUN`，每张表由多行组成，行字段为：序号、焊枪名、客户、时间、担当、规格、备注。

### 5.1 分类与表

- 默认分类**不允许删除**；管理员可新增/重排分类，超级管理员可删除非默认分类（连同其下所有表一并删除）。
- 管理员可在分类下新增表、重命名表、重排表顺序；超级管理员可删除表。
- 一般管理员能看到删除分类和删除表的按钮，但点击时会提示「删除分类属于高风险操作，需要超级管理员权限，请联系超级管理员删除」并阻止。
- 「分类」与「表格列表」标题栏有**恢复默认排序**按钮（仅超级管理员，需二次确认）。
- 命名限制：分类名 1-30 字符且不含 `/`、`\`；表名 1-50 字符，同一分类下表名唯一。

### 5.2 表级独占编辑锁

**每张表同一时刻只允许一个人编辑**（同一用户多标签页共享一把锁）。

- 打开表时申请锁；被他人占用时**无法编辑**，会提示当前编辑者姓名。
- **只读打开**：表被他人锁定时，可点「只读打开」以只读方式查看（不申请锁，禁用所有编辑控件）。
- 持有者完成编辑或切换表时释放锁；表被删除/分类被删除/导入覆盖时强制释放。
- 断线超过 60 秒且无存活连接的僵死锁会被自动清理。

### 5.3 行编辑与焊枪名

- 保存时行序号会被强制重排为严格连续的 `1..N`，杜绝跳号。
- **焊枪名唯一性校验**：同一张表内焊枪名不可重复（空值不计），重复时会拒绝保存并列出重复的序号位置。
- **编号不可修改、前后可自由编辑**：有取号规则的表，非空焊枪名的编号必须与规则计算值一致，手动改编号会被拒绝；**前缀可自由编辑，编号之后也可继续追加后缀**（如 `SRTC-2C15015` → `SRTC-2C15015L` → `SRTC-2C15015-EL` → `SRTC-2C15015L-WL`），编号被自动校正、前后文字原样保留。
- **向下复制（取号）**：点「向下复制」按钮，**或直接在左侧数字框里按 `Enter`**（等同点击加号；客户列为空时不触发）。
  - 数字框表示**本次取号总数（含当前行本身）**：填 3 表示本次共取 3 个号——当前行占 1 个，向下复制 2 行；默认 1 表示只取当前行。
  - 取号时把当前行的客户、时间（当前日期）、担当（当前操作者）填入下方空行。
  - **下方行的焊枪名继承当前行的前缀与后缀，仅编号替换为目标行的规则编号**（即整列只有编号不同）。无取号规则或枪名无法拆分时保留原枪名。
  - 取号完成后数字框自动归 1。
- **末尾 10 个未取号预留行**：每张表在真实行之后固定预留 10 行（序号 `N+1 ~ N+10`，枪名按规则预填）。在任一单元格输入内容即自动提升为真实行（枪名非空时同时补当天日期与当前担当）。
  - **打开或切换表时表格自动滚动到底部**；表名标题栏的「未取号行」按钮（非管理员也可用）可随时一键滑到底部。
- **枪名天蓝色标识**：已被主任务使用的焊枪名显示为天蓝色加粗，实时更新。

### 5.4 任务分配（批量创建确认图任务）

管理员打开表（持有编辑锁、非只读）后，勾选右上角「启用任务分配模式」，每行行首出现复选框。

1. 勾选需要分配的焊枪名。
2. 点「为这些枪名分配确认图任务（N）」打开分配面板。
3. 选择目标设计人员与日期（默认今天），确认提交。

面板右上角有两个开关：

- **任务加急**（默认不勾选）：本次创建的确认图任务全部标记为加急。
- **显示纳期**（默认打开）：按客户列中的仕样号查纳期，任务名自动带 `[M/D]`。

系统按**客户**把选中的枪名分组（客户为空归入「未命名」），每组生成一条任务（任务名 `<客户> 确认图`），组内每个枪名作为枪名行，工时按默认工时规则解析。

**相同仕样号合并**：选定人员与日期后，系统会找该人员当天任务名含「确认图」且不含「确认图修改」、仕样号相同的已有任务。命中时面板显示琥珀色提示，该复选框**默认勾选**（可取消）；命中多条时可进一步选择添加到哪一个。完成提示会区分三种情况（全部合并 / 部分新建部分合并 / 全部新建）。

- **已被主任务使用的焊枪名（天蓝色）不显示勾选框**，避免重复分配。
- 切换表、进入只读模式或离线时会自动退出分配模式并清空勾选。
- **面板可拖动**：按住标题栏空白处可把分配面板挪开，方便对照背后的台账行；每次打开自动回到屏幕中央。

### 5.5 为今日取号安排确认图（Shift×2）

入口有两处：页面**左下角**页脚的「为今日取号安排确认图」按钮（带今日取号数量气泡），或站内**连按两次 `Shift`**。仅管理员可用，离线时拦截。

- 弹窗第一步直接列出**当前登录人员今天取的**全部枪名（判定口径：台账「时间」列等于今天且「担当」列等于当前登录人员姓名），跨分类跨表汇总，**默认全部勾选**。
- 顶部可按仕样号 / 关键字筛选，筛选条件也作用于「全选」。
- **已安排的枪名**显示「已安排」标签且不可勾选，并**统一沉到列表最底部**，第一条已安排行前有吸顶分隔条「已安排 N 个 · 已存在于任务中，不可再分配」，不必先翻过一串灰掉的枪名才能勾选。
- 勾选后选目标设计人员与日期（默认今天），按**客户分组**生成任务（任务名 `<客户> 确认图`）。
- 右上角同样有「显示纳期」（默认打开）与「任务加急」（默认不勾选）开关，预览区实时列出每个分组的最终任务名与纳期。
- 相同仕样号命中时「添加到已有任务」**默认勾选**。
- 提交成功后弹窗关闭、刷新天蓝色标识、并**定位到刚生成的确认图任务**。

> `Esc` 逐层回退：确认图浮层 → 取号结果框 → 取号弹窗。

### 5.6 导入与导出

- **分类导出**（页面入口）：选一个分类 → 单个 `.xls`；选多个分类 → 打包 `.zip`（每个分类一个独立工作簿）。每张表对应一个工作表，列顺序「序号/焊枪名/客户/时间/担当/备注」。
- **系统设置 → 数据管理 → 焊枪编号台账**：按分类导入/导出。导入时工作簿内每个工作表会成为目标分类下的一张表，并**覆盖该分类下全部表**；分类不存在时自动新建。**导入仅超级管理员**。
- **每日编号台账导出**（系统设置 → 数据库维护）：开启后每日定时把全部分类打包为 `.zip`，独立保留天数与目录可配置（默认 30 天）。

### 5.7 默认工时规则（仅超级管理员）

页面工具栏的「默认工时规则」按钮（时钟图标），分三个页签：

| 页签 | 内容 |
|------|------|
| 机型回退规则 | 按枪名机型 C/X 的通用回退工时 |
| 固定任务工时 | 「设计变更」（默认 1.5h）与「既制审图」（默认 0.5h），**不区分机型、不套用表规则** |
| 表专用规则 | 按分类逐表配置「确认图 / 确认图修改 / 设计」三类工时（0-24h，三个值须全填或全空） |

**工时解析优先级**：枪名所在台账表的表级专用规则（超管覆盖值 → 系统内置值）→ 机型 C/X 回退规则 → 固定兜底（确认图 2h / 确认图修改 0.75h / 设计 3h）。枪名机型取枪名首个「-」前一个字符（如 `SRTC-...` → C）。

生效场景：主页面新增/修改枪名时自动填工时（只覆盖自动填充值）、切换任务内容时重算、台账任务分配模式批量建任务时。

### 5.8 默认担当人员

系统内置默认名单（`张啸`、`张明`、`陈青松`、`陈大仪`、`翟世学`、`朱海洋`），作为「担当」列的下拉候选。超级管理员可在「台账初始化」面板修改，或一键重置。

### 5.9 台账初始化（仅超级管理员）

「台账初始化」面板为两级弹窗：

- 第一级：分类选择视图，列出所有分类卡片（可单独初始化本分类），顶部有红色「一键初始化全部表格」按钮。
- 第二级：分类详情视图，逐表展示规则卡片（取号开关/前缀/起始编号/补零位数/保存规则/单表初始化）。

**初始化语义：删除范围内所有表的全部真实行**（连同焊枪名、客户、时间、担当、规格、备注一并删除，**不可恢复**），各表恢复为全新状态，之后只渲染 10 个预留行；同时每张表的取号规则会被**恢复为内置默认号段**（前缀、起始编号、补零位数都回到系统默认，覆盖此前的手工配置；自建表没有内置默认规则则保留原规则）。批量初始化前有红色高危二次确认。

> 范围内任一张表正被他人编辑时**整体拒绝**，不做部分初始化。

## 6. 状态追踪

记录不再手工逐条添加，而是由顶栏「**同步生产大日程**」从「各产品大日程」批量同步。

### 6.1 查看与筛选

- **月份筛选**只按「纳期月」，页面已移除「添加时间月」筛选与行内「添加时间月份」编辑按钮。
- **进入页面时**默认选中产品「焊钳」（南京 + 上海，不含「修改」表）、按纳期升序排列，并自动滚动到设计纳期最近的那一行（该行顶边贴住表头）；它上方那些设计纳期为空的记录需要往上滚才能看到。
- **「纳期」「设计纳期」表头可点击排序**：三态循环（升序 → 降序 → 取消排序恢复原始顺序），默认按纳期升序。纳期按日期先后比较（空值始终排最后），设计纳期按天数数值比较（空值按 0）。排序为前端本地计算，只影响当前筛选后的展示。
- **产品筛选**：顶栏下方六个按钮「焊钳、南京焊钳、上海焊钳、焊钳修改、南京焊钳修改、上海焊钳修改」，单选生效，再点已选按钮或点「显示全部」恢复不限。「焊钳」= 南京 + 上海，「焊钳修改」= 南京修改 + 上海修改。
- **关键词搜索**匹配客户名、仕样号、营业担当、组长，与产品筛选、月份筛选同时生效；导出也按当前选中的产品与合并项导出。
- **行尾「更新信息」按钮**（管理员）按该行仕样号重新取数：数量/纳期/已发图/工厂优先取「各产品大日程」，客户名与营业担当取仕样书 PDF。若大日程共享暂时读不到，会提示「生产大日程共享暂不可用，本次数量/纳期取自仕样书」——这不是同步失败，工厂与已发图保持原值。

### 6.2 同步生产大日程（管理员）

读取「各产品大日程」Excel 的四张工作表（南京焊钳、上海焊钳、南京焊钳修改、上海焊钳修改），把**有效仕样号**（位数与系统配置一致、数量大于 0）按所属月份写入。

- 已存在的记录用表格值覆盖**工厂、客户、数量、纳期、已发图**，并记录来源工作表（供按表筛选）。
- **营业担当、组长等人工维护字段保留**：只在原值为空时补全；表格里客户或纳期为空时不清空原值。
- 点击后先弹**预览框**（将新增/将更新/已一致、有效条数、月份分布、将补全的营业担当/组长条数、被他人编辑中会跳过的条数），确认后才落库，**重复执行幂等**。
- 该按钮默认对一般管理员开放；超级管理员可在页面底部「状态跟踪表权限设置」里关闭**「一般管理员可同步生产大日程」**开关，关闭后一般管理员看到按钮置灰（悬停提示无权限），只有超级管理员能点。
- 同一仕样号拆成多行时：数量与已发图累加、纳期取最早一天。
- **「已发图」与「数量」相等时输入框标绿**，便于识别已发完。
- **共享文件读不到时**：页面会提示无法读取「各产品大日程.xls」（带错误码与处置建议），此时数量/纳期不会更新，已存数据保持不变。后端连续多次读取失败后会暂停访问共享盘一段时间（避免把服务拖死），期间同步会直接提示不可用——先联系 IT 确认共享目录可访问，恢复后重试即可，不需要重启后端。

### 6.3 营业担当 / 组长自动补全

大日程表里没有营业担当列，因此同步时会按仕样号到共享目录找最新版仕样书 PDF，解析签核区的营业担当，再按「组长规则」推出组长。

- 只补空字段，**人工改过的不会被覆盖**；仕样书缺失或解析不到时留空并在预览里提示，不猜测。
- 首次同步约十几秒（要建目录索引），之后只需数秒。
- 共享目录不可访问时同步照常进行，只是不补营业担当。

### 6.4 编辑与并发

- **按行获取编辑锁**：点击/聚焦某一行即申请该行锁，焦点移出整行（或页面卸载、断开连接）时释放。
- 他人锁定期间整行输入框禁用，提示「AAA 正在编辑此记录，请稍后再试」。
- 同一连接同时只持有一行锁，切到别的行会自动释放旧行。
- 新连接进来会先收到当前锁定状态，直接看到他人已占用的行。

### 6.5 组长 / 工厂规则

管理员在本页面可见青色「组长/工厂规则」按钮，弹窗内含「组长规则」与「工厂规则」两个标签页：

- **工厂规则**：维护营业担当到工厂（`O/NJG`、`O/SHA`）的映射并设置默认工厂

超级管理员可一键重置为默认规则。默认值：

### 6.6 导入导出与清理

- **导出**：管理员可「导出显示结果」为 `.xls`（按当前筛选条件），文件名 `status-tracking-YYYYMMDDHHmmss.xls`。开启「全表搜索」导出时会默认过滤掉设计纳期已过期（含纳期为空）的记录，按月份导出则不过滤。
- **导入**（仅超级管理员）：导入前支持「仕样号 + 添加时间月」组合重复检查，可选择覆盖导入。
- **清理**（仅超级管理员，在系统设置「数据库维护」中）：按纳期月或添加时间月清理历史记录。

### 6.7 普通用户只读

普通用户（开启权限后）进入为**只读模式**：顶部显示「当前为只读模式，仅可查看数据，无法编辑」提示条，所有编辑控件禁用，同步/导出/导入入口不可见。

## 7. 设计规范知识库

基于本地部署的 WeKnora 知识库，提供三个功能标签：

| 标签 | 说明 |
|------|------|
| **规范检索** | 关键词检索规范条款，显示命中方式（向量检索/关键词等）与相关度得分 |
| **智能问答** | 基于检索结果流式生成回答，并附带引用出处 |
| **知识库管理** | （一般管理员及以上）按知识库 ID 关联/取消关联，只读查看各库文档清单与解析状态 |

### 7.1 关联知识库

知识库**不再自动发现，需显式关联**：在 WeKnora 控制台打开目标知识库并复制其 ID，回到本页面「知识库管理 → 关联知识库」粘贴，校验通过后保存。

> 取消关联**只移除本系统的关联记录，不会删除 WeKnora 中的知识库**；文档的上传、删除统一在 WeKnora 控制台进行。

### 7.2 检索与问答范围

- 两个功能各有一个**知识库范围多选下拉框**，从已关联知识库中勾选；**未勾选时无法提交**（红色提示），支持全选。
- 下拉项显示文档篇数；接入多个工作空间时，每个库带紫色工作空间标签。
- **问答范围变更后自动开启新会话**，避免沿用旧会话的检索范围。

### 7.3 使用限制

- **规范检索支持跨工作空间**：后端按空间分组并行检索，合并后按相关度排序。
- **智能问答不支持跨工作空间**：所选知识库跨越多个空间时会显示琥珀色提示并禁用发送。
- 某个空间不可访问时页面提示「部分工作空间无法访问」，不影响其他空间。

### 7.4 答复约束提示词（仅超级管理员）

页面底部「答复约束提示词」面板可按知识库配置系统提示词：

- 支持 Markdown，可直接粘贴整篇 `.md` 或从文件导入，单条最长 20000 字符。
- 一次问答选中多个知识库时，取所选范围内**第一个已配置提示词**的库生效。
- 清空提示词会同步删除对应配置；未配置的知识库保持默认行为。
- 仓库内置一份焊枪选型提示词模板，可直接复制使用。

> 页面查看权限与工时管理一致，超级管理员可在页面底部配置一般管理员/普通用户的访问权限。

## 8. 管理后台

分为「设计人员」「登录用户」两个页签，同一时刻只展示一份列表，列表全宽、表头吸顶。

### 8.1 通用

- 两个列表都支持关键词搜索（设计人员匹配姓名/分组，登录用户匹配姓名/用户名）与条件筛选（分组/角色，含「已禁用」），并显示「筛选出 N / 共 M 条」。
- 新增/编辑统一用右侧抽屉表单；初始化名单、批量导入等低频操作收在「更多」菜单。
- **两个列表的表头都可点击排序**：设计人员按「姓名/分组」、登录用户按「姓名/角色/状态」。同一列再点反转方向，换列回到升序，当前排序列文字加深并显示 ↑ / ↓。中文姓名按**拼音**排序；空分组恒排最后、不随升降序翻转；超级管理员恒置顶。
- 排序是**纯展示**，不改变筛选结果，也不写回人员顺序（人员先后仍由主页面姓名悬停的上移/下移按钮维护）。

### 8.2 设计人员

- 用于维护主页面的人员行，**姓名不允许重复**。
- 每行提供「隐藏人员 / 取消隐藏」按钮；隐藏后该人员在主页面「全部」与分组筛选下不再显示，单独选中时仍可见。
- 支持勾选多个后批量删除。
- 设计人员为空时，超级管理员可一键初始化默认名单。
- **批量添加**支持从外部表格复制粘贴导入（列：`name,group`），并提供模板。

### 8.3 登录用户

- 用于维护登录账号，角色支持 `superadmin`、`admin`、`user`。
- 非超级管理员账号为空时，超级管理员可一键初始化默认账号。初始化时为每个账号生成 12 位随机初始密码，结果**仅展示一次**（支持一键复制分发），各账号首次登录后强制改密。
- 支持批量删除、批量禁用/启用，执行前均二次确认；**不能删除/禁用超级管理员，也不能操作当前登录账号**；已是目标状态的自动跳过。
- **操作作用域按权限分级**：只能操作权限低于自己的账号——超级管理员可管理除超级管理员外的所有账号，一般管理员只能操作普通用户。
- **设置权限与重置密码仅超级管理员可用**，一般管理员界面上不展示这两个入口。
- 重置密码（单个或批量）：可手动设置统一密码，也可为每个账号生成独立随机密码（12 位，排除 `0/O/1/l/I` 等易混淆字符）；新密码仅展示一次。**重置后旧会话立即失效**。
- 一般管理员批量添加登录用户时，会自动创建为普通用户。
- **批量添加**支持从外部表格复制粘贴导入（列：`username,password,name,role`，不需要分组列）。
- 批量导入会自动跳过重复数据，并显示导入耗时。

## 9. 系统设置

包含「数据管理」「数据库维护」「登录管理」「日志管理」「计划管理」五个标签页。**后四个仅超级管理员可见**；「数据管理」对一般管理员的开放程度由权限控制。

### 9.1 数据管理

| 功能 | 说明 |
|------|------|
| **任务管理** | 导出渲染后的任务 `.xls`；导入必须用系统导出的格式，**每次只能覆盖导入一个月份**。只解析任务内容/工时列，`当日合计` 和 `月总工时` 会重新计算。导入表格中新增的设计员**不会自动创建**，会跳过并提示。**导入仅超级管理员**；导出超管始终可用，一般管理员需放行（只能导出） |
| **状态跟踪表** | 按**纳期月份**导出 `.xls`（本页与状态追踪页面的「导出显示结果」都有入口）；导入仅超级管理员，支持重复检查与覆盖 |
| **工时管理表** | 按月份导出工时汇总 `.xls`（设计员、总工时、工作日工时、周末加班、出差、请假等列，按总工时倒序，冻结首行首列）。选某个统计分组时导出同步收窄；开启「不含周末加班」「不含休假」时导出数字与列同步跟随 |
| **焊枪编号台账** | 按分类导入/导出（见 5.6） |
| **清理任务数据** | 「清理任务数据」与「清空状态跟踪数据」两个入口，均支持「指定月份 / 该月之前 / 清空全部」三种范围（清空全部为红色二次确认）。清理后提示「已清理 X 张工作表、Y 条任务记录，已回收 Z 磁盘空间」，并**同步作废本地离线缓存**，避免离线时把已删除数据重新渲染出来 |

### 9.2 数据库维护（仅超级管理员）

- **自动维护开关**：启用自动维护、每日数据库备份、每日任务表格导出、每日编号台账导出、每日状态跟踪同步、年度任务清理、断网自动备份。
- **可配置**：最多两个每日执行时间点（默认 `00:30` 和 `12:30`，至少保留一个）、各类保留天数、年度检测月份、月初检测天数、任务保留年数，以及各备份/导出目录。
- **手动操作**：立即备份数据库、立即导出任务数据、立即导出编号台账、清理过期备份、执行年度清理检测、清空所有日志、压缩数据库。
- **运行状态**显示调度器下次执行时间与各目录绝对路径，并列出各类最近 5 个文件。
- **磁盘占用与压缩**：页面会显示「空闲页」体积（已删除但尚未归还给操作系统的空间）。清理任务数据后会**自动压缩一次**；也可手动点「压缩数据库」（需二次确认，压缩期间数据库独占重建，通常只需数秒）。
- 年度清理会先将待删除数据永久归档；断网备份在服务器关闭时自动触发。
- **数据库备份为单地址**：手动与定时备份都只写入配置的备份目录；如需异地留存，需运维侧另行同步。

### 9.3 登录管理（仅超级管理员）

三个开关：

- **多设备同时在线**
- **允许登录用户修改本人设计计划完成状态**（默认开启）
- **允许用户自主改密**（默认关闭）：关闭时所有用户无法自行改密，主页面右上角的改密入口也不显示，需由超级管理员重置；开启后登录用户可点用户名自行改密（需输入当前密码，5 次/15 分钟限流）。

**IP 黑名单**：拦截异常来源访问。支持精确 IP（`192.168.1.100`）、CIDR 网段（`10.0.0.0/24`）和通配符（`192.168.*.*`）三种格式，可一次粘贴多条（逗号、分号、空白分隔均可，单次最多 50 条，总量上限 500 条），可附备注。界面会列出最近登录失败的 IP 供快捷填入。命中规则的 IP 访问任何接口都会收到 403，登录尝试会记录为「IP 已被列入黑名单」。**本机回环地址永不拦截**，规则修改后立即生效。

### 9.4 日志管理（仅超级管理员）

- 展示最新 10 条管理员（超级管理员和一般管理员）的登录记录。
- 点「详细日志」进入操作日志页面（见第 10 章）。
- 操作日志默认最多保留 5000 条，可在本页调整（100 ~ 100000）；登录日志独立保留 2000 条（不可配置）。

### 9.5 计划管理（仅超级管理员）

- **仕样号位数**：设置全局位数（5 或 6 位），影响主页面纳期提取、任务报表仕样进度搜索、状态追踪同步时的有效仕样号判定等**所有**仕样号校验。默认 5 位，切换后立即生效并同步到所有页面。
- **任务内容配色**：任务表格底色的**唯一配置入口**（每项只配底色，文字色固定不可配置）。
  - 卡片按「常规底色」「加急底色」两组展示：常规 7 项（未勾选、确认图、设计、确认图修改、设计变更、既制审图、暂停/取消），加急 3 项（加急确认图、加急设计、加急确认图修改）。
  - 卡片顶部为实时预览（文字直接呈现该状态下的真实文字色）。
  - 每项可取色器 + 十六进制输入，单项可「默认」回退；改完点「保存配色」，「恢复默认」立刻把全部改回默认值。
  - 保存后**无需刷新即可在全站生效**。

> 组长规则与工厂规则配置不在本页面，入口在状态追踪页面（见 6.5）。

## 10. 操作日志

操作日志回答的是「**谁改了什么**」，而不是「谁打开了页面」。因此只记**改变状态**的操作：

- **写操作全记**：新增、修改、删除类操作全部记录。
- **读取只记敏感操作**：各类导出会记录。
- **常规刷新不记**：页面每次刷新的初始化读取不记录，避免真正的增删改被读请求淹没。
- **会话心跳不记**。

日志内容包含操作描述、操作类型、IP、浏览器信息、状态码、耗时等。操作类型和描述均为**中文**（如「用户登录」「添加任务」「更新任务」「删除任务」「移动任务」「重新排序设计员」「批量替换任务」「导出任务数据」）。

- 浏览器信息只显示浏览器名称（如「Chrome」）。
- 仅超级管理员可查看，支持按用户名、操作类型、IP、日期范围筛选，并支持导出 `.xls`。
- 筛选下拉框中的操作类型按**拼音排序**。

## 11. 权限速查

> 前提：以下角色权限**仅在在线时生效**。任何角色在离线模式下都会被降级为只读——管理员的任务编辑、枪名移动、标记颜色、撤销/重做入口一并隐藏，`Shift`×2 / `Space`×2 / `~`×2 三条快捷键彻底停用，只保留 `Ctrl`×2 定位今日任务。

### 超级管理员 `superadmin`

- 查看和编辑所有任务
- 管理设计人员、一般管理员和普通用户（含禁用/启用）
- 配置任务报表、工时管理、状态追踪、焊枪台账和系统设置
- 导入导出所有系统数据（任务、状态跟踪、工时、焊枪台账）
- 管理台账分类/表/行，配置枪名规则、执行台账初始化、管理默认担当与默认工时规则
- 关联/取消关联设计规范知识库，配置答复约束提示词
- 查看管理员登录信息与详细操作日志
- 重置任意用户密码（重置**本人**时需验证当前密码）

### 一般管理员 `admin`

- 查看和编辑任务
- 管理设计人员
- 创建普通用户账号
- 配置和管理组长规则、工厂规则（重置为默认仅超级管理员）
- 可新增/重命名/重排台账分类与表、编辑行（打开表时获取表级锁），但**不能删除分类或表**
- 可关联/取消关联设计规范知识库并查看文档清单
- 能否进入任务报表、工时管理、状态追踪、焊枪台账，取决于对应页面的「一般管理员」开关
- 能否进入系统设置数据管理，取决于「一般管理员」开关（只能导出，不能导入）

### 普通用户 `user`

- 可查看主页面，**但不能新增、编辑、删除、拖拽移动或复制任务**
- 在满足条件时可对**本人同名设计员**的设计计划任务标记完成状态（见 2.11）
- 首次登录需改密；被重置密码后旧会话立即失效
- 能否进入任务报表、工时管理、状态追踪，取决于对应页面的「普通用户」开关
- 焊枪台账开启普通用户权限后为**只读模式**（可浏览，不申请编辑锁，无任何编辑入口）

## 12. 常见提示语速查

| 提示语 | 出现场景 | 怎么处理 |
|--------|----------|----------|
| `当前离线，禁止编辑` | 离线时尝试任何写操作 | 等网络/后端恢复；主页面仍可浏览缓存 |
| `当前处于离线模式，此页面禁止编辑` | 离线时进入各功能页 | 同上 |
| `AAA 正在编辑该任务，暂无法操作` | 同一条主任务被他人占用 | 等对方结束，或改编辑其它任务 |
| `AAA 正在修改该任务的完成状态，暂无法操作` | 对方正在改该任务完成状态 | 稍后重试 |
| `目标已存在内容完全相同的主任务「xxx」，拒绝复制/拒绝移动` | 拖拽产生重复任务 | 改目标单元格，或先删除重复项 |
| `只能复制同一个人同一天的主任务，请重新选择` | `~`×2 跨单元格多选 | 只选同一人同一天的任务 |
| `请先选中主任务，再连按两次 ~ 复制` | `~`×2 时没有选中任务 | 先点选任务（蓝色描边） |
| `再按一次 ~ 复制选中主任务为表格` | 第一次按 `~` | 再按一次 |
| `已复制为纯文本（当前浏览器不允许写带格式剪贴板）` | 浏览器限制富文本剪贴板 | 纯文本可用；换用 localhost/HTTPS 访问可保留表格 |
| `同一主任务内请使用枪名行的上移/下移箭头调整顺序` | 枪名拖到自己所在任务内 | 用上移/下移箭头 |
| `目标主任务已存在枪名「xxx」，无法移动` | 枪名重名 | 改名或换目标 |
| `目标主任务没有枪名，不能移入枪名` | 目标是只有主任务内容的空行 | 换一个有枪名的目标 |
| `该位置没有主任务，请拖到已有主任务上，或拖到该格最下面的加号上新建主任务` | 拖到已有任务的格子里但没压住任务行 | 拖到任务行或加号上 |
| `当前不在本月视图，无法定位今日任务` | 连按 `Ctrl` 但不在本月 | 先切回本月 |
| `密码已被管理员重置，请使用新密码重新登录` | 管理员重置了你的密码 | 用新密码登录 |
| `系统已禁用自主修改密码，请联系管理员` | 「允许用户自主改密」关闭时尝试改密 | 联系超级管理员重置 |
| `删除分类属于高风险操作，需要超级管理员权限，请联系超级管理员删除` | 一般管理员删分类/表 | 找超级管理员 |
| `只有确认图 / 设计 / 确认图修改有加急状态` | 对设计变更/既制审图/暂停取消勾加急 | 该内容不支持加急 |
| `部分工作空间无法访问` | 某个 WeKnora 空间 Key 失效 | 检查对应空间的 API Key |
| `当前为只读模式，仅可查看数据，无法编辑` | 普通用户进入状态追踪/台账 | 联系管理员开通权限 |
